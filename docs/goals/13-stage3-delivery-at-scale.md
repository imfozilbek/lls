# Цель 13. Этап 3: доставка на масштабе

**Статус:** ⏳ · **Зависит от:** 11, 06 (и 12, если корзины из нескольких точек) · **Сейчас запрещено правилами**

## Зачем
Когда заказов в районе много, доставщик за одну поездку забирает заказы из нескольких точек и
везёт нескольким клиентам. Доставка дешевле и быстрее, доставщик зарабатывает больше. Это
последняя часть видения: доставка района — полноценный самостоятельный продукт.

## Важно
`CLAUDE.md` сейчас запрещает маршруты и автоматическую раздачу заказов. Цель начинается
**только после решения владельца** «начинаем этап 3». Первый шаг — обновить правила.

## Что нужно от владельца
- Решение «начинаем этап 3».
- Тарифы доставки (за поездку, за километр, за точку) и доля Zumda.
- Допустима ли автоматическая подсказка «возьми ещё этот заказ по пути».

## Что сделать
1. **Правила:** обновить `CLAUDE.md` и ROADMAP.
2. **Поездка:** сущность `Trip` — несколько заказов у одного доставщика, порядок забора и
   доставки. Доставщик сам добавляет заказы «по пути»; система подсказывает, но не раздаёт сама,
   пока владелец не разрешит.
3. **Расстояния:** по координатам точек и клиентов, без платных карт. Цена доставки по тарифу
   владельца.
4. **Деньги:** заказы оплачены переводом на карты точек до готовки, доставщик денег не везёт;
   плата за доставку по тарифу; отчёт доставщика за день.
5. **Нагрузка:** проверить лимиты бесплатного тарифа на реальном объёме. Если пора — предложить
   владельцу Workers Paid ($5/мес) с цифрами.
6. **e2e:** поездка с двумя точками и тремя клиентами → все доставлены → отчёт доставщика.

## Definition of done
- [ ] Правила обновлены владельцем до начала работы.
- [ ] Доставщик берёт несколько заказов в одну поездку; порядок виден; клиенты получают статусы.
- [ ] Цена доставки считается по тарифу владельца; доставщик видит заработок за день.
- [ ] Касса по точкам не смешивается.
- [ ] Гейты зелёные; e2e зелёный 3 раза подряд; нагрузка проверена.
- [ ] Документы обновлены; PR слит.

## Чего не делаем
- Платные картографические API без решения владельца.
- Выход в другой город — отдельное решение после этого этапа.
