# Цель 09. Тип «услуга»: чистка ковров и автомойка

**Статус:** ⏳ · **Зависит от:** 02 (процесс, согласованный с Jasur)

## Зачем
Не каждая точка продаёт товар. Чистка ковров и автомойка — тоже офлайн-точки, которые хотят
заказы онлайн. По правилам проекта услуги входят в этап 1 отдельным типом бизнеса, как только
согласован процесс с клиентом.

## Что нужно от владельца
- Ответы Jasur на блок «avto va gilam yuvish» из `docs/pilot-meeting.md`: как оформляется
  заказ, как считается цена, сроки, когда берутся деньги.

## Что сделать
1. **Ковры** («забрать → почистить → вернуть»):
   - **ядро:** тип бизнеса `service`; заказ услуги без фиксированной суммы в момент заказа.
     Цена считается после замера: владелец вводит площадь в м² × цену за м² в целых сумах, и
     клиенту приходит итог на подтверждение;
   - **статусы** в общей таблице переходов: «заявка → забрали → моем → готово → везём →
     вернули». Курьерские шаги — у доставщика (свой или сеть, цели 05–06). Таблица переходов
     остаётся одной — по типу бизнеса, по правилу «ONE transitions table»;
   - **деньги:** оплата при возврате (или как скажет Jasur) — тот же `Payment`.
2. **Автомойка** (запись на время):
   - **слоты:** длительность услуги, число постов, часы работы (`working-hours.ts`);
   - **цена** по типу машины (легковая, кроссовер, джип) — это варианты услуги (если цель 03
     сделала варианты, переиспользовать их);
   - **запись:** клиент выбирает время; владелец видит расписание дня; напоминание клиенту
     перед записью.
3. **Тексты** по типу бизнеса (uz/ru), как у еды, воды и продуктов (`telegram/texts.ts`,
   `app/src/i18n/*`).
4. **e2e** для каждого процесса.
5. **Документы:** `CLAUDE.md` (тип `service` в Domain Models и статусы), инструкция владельцу,
   CHANGELOG, ROADMAP.

## Definition of done
- [ ] Процесс ковров и автомойки записан со слов Jasur и совпадает с реализацией.
- [ ] Ковры: заявка → забор → замер и цена → подтверждение клиентом → возврат → оплата; e2e
      зелёный.
- [ ] Автомойка: клиент записывается на свободное время, два клиента не занимают один пост в
      одно время (тест на гонку), владелец видит день; e2e зелёный.
- [ ] Одна таблица переходов в ядре; товарные бизнесы не изменились (старые тесты зелёные).
- [ ] Гейты зелёные; документы обновлены; PR слит; Jasur принял работу на реальных заказах.

## Чего не делаем
- Выезд мойщика к клиенту — если Jasur не подтвердит.
- Онлайн-оплату записи.
