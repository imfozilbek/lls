# Цели Zumda: путь до полного видения

Видение продукта (из `CLAUDE.md`): каждая офлайн-точка в радиусе 20–30 км района становится
онлайн-точкой. У каждой точки свой бот. Своя доставка района: с первых версий. Zumda
зарабатывает на объёме: сервисный сбор с каждого заказа, подписка, комиссия витрины, товары для
доставки. Потом: маркетплейс района и доставка на масштабе.

Этот путь разложен на цели. Каждая цель лежит в отдельном файле: зачем, что сделать, как сделать и
**definition of done** (DoD): чек-лист, после которого цель закрыта.

## Как пользоваться

Владелец пишет: **«Дай, друг, дай следующую цель»**. Claude:

1. Открывает этот файл и берёт **первую цель сверху**, у которой статус не ✅ и все
   зависимости ✅.
2. Если цель ждёт задачу владельца (ключи, решение, встреча), говорит, **что именно нужно от
   владельца**, и предлагает следующую цель, которую можно делать без него.
3. Кратко показывает цель: зачем, что будет сделано, что нужно от владельца.
4. Работает по правилам `CLAUDE.md`:
   - план и одобрение;
   - коммиты по модулям, гейты перед каждым коммитом;
   - PR и слежение за ним до слияния.
5. Ставит ✅ в таблице **только когда выполнен весь DoD**. Если пункт DoD нельзя закрыть,
   цель остаётся 🔨, и Claude говорит, что мешает.
6. Если по ходу появилось новое знание (ответ пилота, решение владельца), обновляет цель и этот
   файл в том же PR.

Статусы: ⏳ не начата · 🔨 в работе · ⛔ ждёт владельца · ✅ DoD выполнен.
