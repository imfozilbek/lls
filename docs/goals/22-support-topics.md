# Цель 22. Группа поддержки: довести до подключения и сделать удобной

**Статус:** 🔨 код готов, ждёт проверки на живой группе · **ROADMAP:** M4t · **Зависит от:** 21

## Зачем
Цель 21 дала магазину группу с темами: вопрос клиента попадает в его тему, ответ уходит клиенту.
Владелец решил, что без группы никак. Значит, надо, чтобы владелец до неё дошёл, а помощницы с
первого взгляда видели, кто ждёт ответа и кто этот клиент.

## Решения владельца (24 ноября 2026)
1. Шаг в «Ishga tayyor»: да, обязательный.
2. Подробные шаги текстом (без видео). Пункты меню Telegram по-узбекски, в скобках по-английски:
   «Mavzular» (Topics). Русских слов нет.
3. Причина отказа видна в приложении: да.
4. Статус темы: эмодзи-значок ❓ ждёт, ✅ ответили. Закрепить тему или поменять порядок тем бот
   не может (проверено по справочнику Bot API 10.5): Telegram ставит наверх тему со свежим
   сообщением.
5. Автоответ ночью: не нужен.
6. Новые заказы в теме клиента: да.
7. Название темы «Имя · телефон». У темы нет поля «описание»: его роль играет закреплённая
   карточка. В ней же постоянный клиент («⭐ 5 ta buyurtma»). Цвет кружка не используем: эмодзи-
   значок его закрывает.

## Что сделано
- **«Ishga tayyor»:** обязательный шаг «Mijozlar savollari uchun guruh». Он готов, когда группа
  подключена (`supportChat`), и ведёт в «Sozlamalar» → «Mijozlar savollari». У демо-магазина
  шага нет.
- **«Qanday qilinadi?»** под каждым из трёх шагов: что нажать в Telegram на Android и iPhone.
- **Отказ в приложении:** последний отказ или потеря группы хранятся в `support_refusals` и
  стираются при подключении. `GET /api/owner/support` отдаёт `refusal`. Приложение показывает
  красный блок (««Oddiy guruh» guruhi bog'lanmadi» и почему) с «Qayta urinish». Если отказ пришёл
  после нажатия «Guruhni bog'lash», ожидание прекращается.
- **Значок:**
  - новая тема создаётся с ❓;
  - ответ помощницы ставит ✅, новый вопрос клиента снова ставит ❓;
  - тему, закрытую людьми, вопрос клиента открывает заново.
  - Значок меняется только при смене состояния (`support_threads.waiting_since`, один условный
    UPDATE), поэтому второй вопрос подряд или второй ответ ничего не трогают.
  - Значки берутся из набора Telegram (`getForumTopicIconStickers`) один раз на процесс; если
    нужного нет, тема работает без значка.
- **Название** «Aziz Karimov · 90 123 45 67»:
  - имя обрезается до 20 знаков;
  - без телефона, данного этому магазину, «· @username», без него только имя;
  - переименование только когда название меняется (`topic_name`).
- **Закреплённая карточка** вверху темы:
  - имя, @username, 📞 телефон этого магазина;
  - «🆕 Yangi mijoz» или «⭐ N ta buyurtma» (до «10+», счёт с ограничением в 11 строк);
  - последний заказ.
- **Новый заказ клиента с темой:** тихая строка «🛒 #14 · 96 000 so'm · karta», карточка
  правится на месте, название получает телефон. Удалённая карточка отправляется заново и
  закрепляется.
- **Старые темы** (созданы до цели 22, без названия и карточки): на следующем сообщении клиента
  тема один раз получает «Имя · телефон» и закреплённую карточку (`unnamed` в маршруте).
- Миграция `0038` (только добавления). Тесты core, worker (маршруты, шлюз, EXPLAIN, бюджет D1),
  e2e `support.spec.ts`. Слова через корпус Prizma.

## Нагрузка
- **Первое сообщение клиента:** 20 чтений, 3 записи. Карточка читает телефон этого магазина и до
  11 заказов.
- **Следующее сообщение:** 4 чтения, 0 записей.
- **Ответ:** 5 чтений, 1 запись (✅). Запись бывает один раз за оборот разговора, а не на каждое
  сообщение.
- **Заказ клиента с темой:** около 15 чтений и 0–1 запись. Без группы +1 чтение.

## Что меняется для всех магазинов
Готовые магазины снова видят «Ishga tayyor» с одним шагом, пока не подключат группу. Это и есть
решение «без группы никак».
