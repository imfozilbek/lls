# Цель 07. Онлайн-точка за час

**Статус:** ⏳ · **ROADMAP:** M7 · **Зависит от:** 06 (сеть доставщиков)

## Зачем
Чтобы превратить в онлайн-точки **все** точки района, подключение должно быть быстрым. Главные
барьеры: у точки нет доставщика (решает цель 06), каталог из сотен товаров (продукты), и клиент
хочет забрать сам. Цель: от «хочу» до первого заказа — за час.

## Что нужно от владельца
- Кто заполняет каталоги новых точек: вы, помощник или сама точка с нашей помощью.

## Что сделать
1. **Самовывоз:**
   - **Ядро.** Способ получения: `delivery` или `pickup`. Для самовывоза нет адреса, доставки
     и доставщика. Статусы `ready → delivered`, а шаг `picked_up` пропускается — правило
     прописать в той же таблице переходов (`domain/enums/order-status.ts`) рядом с правилом
     актора.
   - **Деньги.** Оплату у кассы фиксирует владелец, как сейчас «Доставлен × как заплатили».
   - **Настройки.** Владелец включает «Самовывоз» в «Мой магазин». Клиент выбирает
     «Доставка / Заберу сам» в оформлении.
   - **Тексты** uz/ru, тесты, e2e.
2. **Импорт каталога из Excel или CSV:**
   - шаблон файла (название, цена, единица, раздел, шаг для кг);
   - загрузка в «Мой магазин → Каталог»;
   - предпросмотр с ошибками по строкам;
   - сохранение одним `db.batch`;
   - лимит строк в одном файле — под бесплатный тариф D1 (лимит записей в день);
   - тесты на разбор файла и на ошибки.
3. **Помощь при подключении:**
   - админ в боте LLS: `/assist <slug>` — временный доступ помощника LLS к каталогу точки (с
     записью, кто и когда);
   - в инструкции — «как подключить точку за час».
4. **Точка без своих доставщиков** при подключении сразу получает «доставка сетью района»
   (цель 06) — без шага «пригласите доставщика».
5. **Документы:** инструкция владельцу (самовывоз, импорт), CHANGELOG, ROADMAP M7.

## Definition of done
- [ ] Самовывоз: клиент выбирает «Заберу сам», владелец отмечает выдачу и оплату; шаг
      «в пути» для самовывоза не показывается; e2e зелёный.
- [ ] Импорт: файл на 300 товаров загружается с предпросмотром; ошибки показаны по строкам;
      повторная загрузка не создаёт дублей.
- [ ] Помощник LLS может заполнить каталог точки по `/assist`, доступ временный и записан.
- [ ] Проверено на одной реальной точке: от заявки до первого заказа — не больше часа.
- [ ] Гейты зелёные; бюджет JS клиента ≤ 100 КБ gzip (импорт только в чанке владельца).
- [ ] Документы обновлены; PR слит.

## Чего не делаем
- Распознавание каталога по фото (только если точка попросит).
- Склад и остатки.
