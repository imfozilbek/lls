# Цель 12. Этап 2: маркетплейс района

**Статус:** ⏳ · **Зависит от:** 11 (район покрыт) · **Сейчас запрещено правилами**

## Зачем
Когда точки района онлайн и есть сеть доставки, LLS становится маркетплейсом района: клиент
собирает **одну корзину из нескольких точек**, а сеть привозит её. Это следующий уровень
видения.

## Важно
Сейчас `CLAUDE.md` запрещает общую корзину («Build ONLY stage 1»). Цель начинается **только
после решения владельца** «начинаем этап 2». Первый шаг цели — обновить правила.

## Что нужно от владельца
- Решение «начинаем этап 2».
- Комиссия маркетплейса и как она сочетается с сервисным сбором.
- Правила для клиента: минимальная сумма, доставка из нескольких точек одной поездкой или
  несколькими.

## Что сделать
1. **Правила:** обновить `CLAUDE.md` (этапы, «Still forbidden», модели) и ROADMAP.
2. **Ядро:**
   - общая корзина района разбивается при оформлении на заказы по точкам (каждый со своим
     номером, деньгами и снимками сбора и комиссии);
   - заказ клиента связывает их;
   - отмена и деньги — по каждой части отдельно.
3. **Доставка:**
   - до цели 13 — по одной точке за поездку; каждый заказ берёт доставщик сети;
   - клиент видит общий статус и статусы частей.
4. **Витрина:** фильтр района (`TODO.md` №10), разделы по всем точкам, «Добавить» из разных
   точек в одну корзину.
5. **Деньги:** клиент платит каждой части отдельно переводом на карту её точки, до готовки
   (наличных нет). Расчёты между бизнесами через LLS по-прежнему не делаем, если владелец не
   решит иначе.
6. **e2e:** корзина из двух точек → два заказа → две доставки → деньги каждой точке.

## Definition of done
- [ ] Правила обновлены владельцем до начала работы.
- [ ] Клиент собирает корзину из 2+ точек района и оформляет её одним действием.
- [ ] Каждая точка получает свою часть со своими деньгами и снимками; сеть доставляет.
- [ ] Комиссия маркетплейса и сервисный сбор считаются по решению владельца.
- [ ] Гейты зелёные; e2e зелёный 3 раза подряд; бюджет JS клиента ≤ 100 КБ gzip.
- [ ] Документы обновлены; PR слит.

## Чего не делаем
- Несколько точек за одну поездку и маршруты — это цель 13.
