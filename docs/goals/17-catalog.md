# Цель 17. Любой товар за минуту: каталог Zumda

**Статус:** ⏳ · **ROADMAP:** M4r · **Зависит от:** 01

## Зачем
Владелец любой точки (продукты, еда, услуги, хозтовары) добавляет товар за минуту и не мучается:
набирает пару букв, выбирает готовую позицию, пишет только цену. Фото ставит сам.

## Что есть
Исследование октября 2026: `docs/catalog-research/`. Там 3 405 позиций: Yandex Lavka и Makro,
меню 25 заведений на Wolt, услуги OLX.uz; единицы взяты с buxgalter.uz.

## Решения владельца (до кода)
1. Варианты и добавки делаем вместе с каталогом (предложение: да).
2. Общий список разделов растёт с 20 до ~60–70 (предложение: да).
3. Новый вид бизнеса «Do'kon»: непродуктовый магазин.
4. Услуги с лицензией (медицина, ветеринар, газ, нотариус) убрать из каталога (предложение: да).
5. «Narxi ... dan» для услуг; цена «после осмотра» остаётся в цели 09.

## Что сделать
1. **Каталог:**
   - свести 4 JSON в один без дублей;
   - проверить сомнительные слова (Mol jaz, Qo'y jaz, bargak, lochira…);
   - сверить непродуктовые товары с реальными каталогами;
   - отдать статическим файлом приложения, который грузится только при поиске: не в бандле
     покупателя, $0.
2. **Единицы (ядро, только добавления):**
   - граммы: 100 g и 1 g. Для цены за 100 g сумма = цена × граммы / 100, считает только сервер;
   - товары: 20 l, qadoq, quti, bog', to'plam, juft, metr, m², kub, qop, rulon, list, lotok;
   - услуги: soat, kun, oy, seans, reys, sotix.
3. **Варианты и добавки:**
   - в товаре: вариант (один выбор со своей ценой) и добавки (несколько, с ценой);
   - в заказе: снимок выбора, цену считает сервер;
   - миграция только с добавлениями;
   - выбор в карточке покупателя отдельным чанком (бюджет 100 КБ).
4. **Форма товара:**
   - поиск по каталогу сверху и блок «Mijoz shunday ko'radi»;
   - раздел и единица угадываются сами;
   - «Saqlash va yana qo'shish» и «Nusxa olish»;
   - черновик не теряется (`useClosingGuard`), ошибки видны у поля.
5. **«Ro'yxat bilan qo'shish»:**
   - много строк вида «Nomi narx [kg|litr]»;
   - предпросмотр с ошибками по строкам;
   - сохранение одним `db.batch`, лимит строк под бесплатный D1.
6. **Тексты:** только узбекский. Бот, заказ, CSV и сообщения показывают вариант и добавки.
7. **e2e и документы:** CLAUDE.md (единицы, варианты), инструкция владельцу, CHANGELOG, ROADMAP.

## Definition of done
- [ ] Владелец принял решения 1–5, они записаны здесь
- [ ] Каталог в коде, сомнительные слова проверены или убраны
- [ ] Поиск «osh», «murch», «gilam», «sement» находит позицию. Выбор заполняет всё, кроме цены.
      «O'zim yozaman» работает
- [ ] Граммы: «Qora murch» продаётся по 100 g, заказ на 300 g считает сумму верно (тест ядра)
- [ ] Все новые единицы видны в форме, витрине, корзине, заказе, сообщениях и CSV
- [ ] Варианты и добавки: «Latte 0,4 l + sirop» попадает в заказ с верной суммой. Подделка цены
      с клиента отвергается (тест Worker)
- [ ] «Ro'yxat bilan»: 50 строк за раз, ошибочная строка подсвечена, дублей нет
- [ ] Черновик не теряется по «назад»; «Saqlash va yana qo'shish» и «Nusxa olish» работают
- [ ] Бюджет JS покупателя ≤ 100 КБ gzip; запросы и строки D1 записаны в `docs/capacity.md`
- [ ] e2e для еды, продуктов (граммы), услуги (m²) и списка; гейты зелёные
- [ ] На проде: пилот добавил 10 товаров через каталог и получил по ним заказ
- [ ] CLAUDE.md, инструкция владельцу, CHANGELOG, ROADMAP обновлены; PR слит

## Чего не делаем
- Фото из каталога.
- Цены в каталоге.
- Импорт Excel: это цель 07.
- Цену после осмотра: это цель 09.
