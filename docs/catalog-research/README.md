узбекском латиницей.

Источники каждого файла перечислены в его поле `sources`, выводы записаны в `findings`.

## Что проверить до использования
- **Непродуктовые товары:** сверить с реальными каталогами (Texnomart, Uzum, строительные рынки).
- **Слова, которые агенты не подтвердили источником:**
  - блюда: Mol jaz, Qo'y jaz, Chiroqchi salati, Qashqadaryo oshi;
  - курага: bargak, turshak, qand o'rik;
  - хлеб: lochira, fatir, chaqmoq;
  - чай: Ko'k choy 95/110.
- **Korzinka, Uzum и Carrefour не открылись.** Korzinka ответила 403, Uzum требует входа,
  Carrefour отдал пустую страницу.
- **Цены в выводах в основном ташкентские.** Это только для понимания единиц, в каталог цены не
  идут.
- **Услуги с лицензией** помечены в `note`: медицина, ветеринар, газ, дезинфекция, нотариус.
